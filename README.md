## Descripción general del lenguaje y la plataforma .NET

C# es un lenguaje que se lanzó oficialmente en febrero de 2002, junto con la plataforma .NET 1.0 de Microsoft, a la que está intrínsecamente vinculado. C# requiere este entorno de ejecución para funcionar, el cual proporciona un conjunto muy amplio de clases.

A primera vista, la plataforma .NET es un entorno de ejecución similar a una máquina virtual Java, con algunas diferencias notables:

**Multiplataforma**: mientras que Java se ha ejecutado en diversos sistemas operativos desde sus inicios, .NET se limitaba inicialmente a Windows. Sin embargo, el proyecto **[Mono](http://www.mono-project.com)** permite ahora utilizar .NET en sistemas como Unix y Linux.


**Multilenguaje**: La plataforma .NET permite ejecutar programas escritos en diferentes lenguajes, siempre que su compilador genere código IL (lenguaje intermedio). Todas las clases de .NET están disponibles para estos lenguajes, lo que tiende a difuminar las diferencias entre ellos; elegir un lenguaje .NET se convierte entonces en una cuestión de preferencia más que de rendimiento.





## Evolución del lenguaje

En 2002 (C# 1.0), el lenguaje era muy similar a Java, lo que facilitaba la transición de un entorno a otro. Desde entonces, las características específicas de cada lenguaje se han vuelto más diferenciadas.

Con la llegada de C# 3.0 y el marco .NET 3.5, surgieron numerosas características nuevas, de las cuales la más significativa es probablemente **LINQ** (Language INtegrated Query). LINQ permite consultar matrices, listas, bases de datos o archivos XML de manera uniforme (similar a SQL).
