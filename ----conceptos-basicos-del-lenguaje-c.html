    • las instrucciones que las gestionan

    Arriba, los tipos de C# se indican mediante su tipo .NET equivalente, con el comentario (S) si el tipo es una estructura y (C) si el tipo es una clase. Se ha descubierto que hay dos tipos posibles para un entero de 32 bits: int e Int32. El tipo int es un tipo de C#. Int32 es una estructura que pertenece a System. Su nombre completo es System.Int32. El tipo int es un alias de C# para la estructura .NET System.Int32. Del mismo modo, la cadena de C# es un alias para el tipo .NET System.String. System.String es una clase y no una estructura. Los dos conceptos son similares, pero con la siguiente diferencia fundamental:

    • una variable de tipo Estructura se puede manipular a través de su valor
    • una variable de tipo Clase se puede manipular a través de su dirección (referencia en lenguaje de objetos).

    Tanto una estructura como una clase son tipos complejos con atributos y métodos. Por ejemplo, podemos escribir:

    string nomDuType=3.GetType().FullName;

    En el ejemplo anterior, el literal 3 es, por defecto en C#, un entero (int) del tipo System.Int32 de .NET. Esta estructura cuenta con un método GetType() que devuelve un objeto que encapsula las características del tipo de datos System.Int32. Entre ellas se encuentra la propiedad FullName, que devuelve el nombre completo del tipo. Como se puede ver, el literal 3 es más complejo de lo que parece a primera vista.

    3.2.3. Informes de datos

    3.2.3.1. Función de las declaraciones

    Un programa manipula datos caracterizados por un nombre y un tipo. Estos datos se almacenan en la memoria. Cuando se compila el programa, el compilador asigna a cada elemento de datos una ubicación en la memoria caracterizada por una dirección y un tamaño. Lo hace con la ayuda de las declaraciones realizadas por el programador.

    También permiten al compilador detectar errores de programación. Por ejemplo, la

    x=x*2;

    se declarará erróneo si x es una cadena, por ejemplo.

    3.2.3.2. Declaración de constantes

    La sintaxis para declarar una constante es la siguiente:

        const type nom=valeur;          //définit constante nom=valeur

    Por ejemplo:

    const float myPI=3.141592F;

    ¿Por qué declarar constantes?

    1. El programa será más fácil de leer si se le da a la constante un nombre significativo: 
        const  float taux_tva=0.186F;
    1. Modificar el programa será más fácil si cambia la «constante». Por ejemplo, en el caso anterior, si el tipo de IVA cambia al 33 %, la única modificación que habrá que hacer será modificar la instrucción que define su valor: 
        const float taux_tva=0.33F;

    Si se hubiera utilizado 0,186 explícitamente en el programa, habría que modificar muchas instrucciones.

    3.2.3.3. Declaración de variables

    Una variable se identifica mediante un nombre y hace referencia a un tipo de datos. C# distingue entre mayúsculas y minúsculas. Por lo tanto, FIN y end son diferentes.

    Las variables se pueden inicializar al declararlas. La sintaxis para declarar una o más variables es:

     Identificateur_de_type variable1[=valeur1],variable2=[valeur2],...;

    donde Identificador_de_tipo es un tipo predefinido o un tipo definido por el programador. Opcionalmente, una variable puede inicializarse además de declararse.

    También se puede evitar especificar el tipo exacto de una variable utilizando la palabra clave var en lugar de Identificador_de_tipo:

     var variable1=valeur1,variable2=valeur2,...;

    La palabra clave var no significa que las variables no tengan un tipo específico. La variable variablei tiene el tipo de datos valori que se le ha asignado. La inicialización es aquí obligatoria para que el compilador pueda deducir el tipo de la variable.

    He aquí un ejemplo:

    
using System;
 
namespace Chap1 {
    class P00 {
        static void Main(string[] args) {
            int i=2;
            Console.WriteLine("Type de int i=2 : {0},{1}",i.GetType().Name,i.GetType().FullName);
            var j = 3;
            Console.WriteLine("Type de var j=3 : {0},{1}", j.GetType().Name, j.GetType().FullName);
            var aujourdhui = DateTime.Now;
            Console.WriteLine("Type de var aujourdhui : {0},{1}", aujourdhui.GetType().Name, aujourdhui.GetType().FullName);
        }
    }
}
    • línea 6: datos tipados explícitamente
    • línea 7: (data).GetType().Name es el nombre corto de (data), (data).GetType().FullName es el nombre completo de (data)
    • línea 8: datos de tipado implícito. Como 3 es de tipo int, j será de tipo int.
    • línea 10: datos de tipado implícito. Dado que el tipo de DateTime.Now es DateTime, el tipo de today será DateTime.

    Más adelante veremos que es posible declarar un tipo «sobre la marcha» en una expresión. En este caso, se trata de un tipo anónimo, es decir, un tipo al que el usuario no ha dado nombre. El compilador asignará un nombre a este nuevo tipo. Si se va a asignar un tipo anónimo a una variable, la única forma de declararlo es utilizando la palabra clave var.

    3.2.5. Tablas de datos

    Una matriz en C# es un objeto que se utiliza para agrupar datos del mismo tipo bajo un mismo identificador. Su declaración es la siguiente:

    Type[] tableau[]=new Type[n]

    n es el número de elementos de datos que puede contener la matriz. La sintaxis Table[i] designa el dato número i, donde i pertenece al intervalo [0,n-1]. Cualquier referencia al dato Table[i] en la que i no pertenezca al intervalo [0,n-1] provocará una excepción. Una matriz se puede inicializar además de declararse:

        int[] entiers=new int[] {0,10,20,30};

    o simplemente:

        int[] entiers={0,10,20,30};

    Las matrices tienen una propiedad llamada «Longitud», que es el número de elementos que contiene la matriz.

    Una matriz bidimensional se puede declarar de la siguiente manera:

    Type[,] array = new Type[n, m];

    donde n es el número de filas y m el número de columnas. La sintaxis Table[i,j] designa el elemento j en la fila i de la tabla. La matriz bidimensional también se puede inicializar al mismo tiempo que se declara:

        double[,] réels=new double[,] { {0.5, 1.7}, {8.4, -6}};

    o simplemente:

        double[,] réels={ {0.5, 1.7}, {8.4, -6}};

    El número de elementos en cada dimensión se puede obtener utilizando GetLength(i), donde i=0 representa la dimensión correspondiente al primer índice, i=1 la dimensión correspondiente al segundo índice, ...

    El número total de dimensiones se obtiene con la propiedad Rank, y el número total de elementos con la propiedad Length.

    Una tabla de tablas se declara de la siguiente manera:

    Type[][] array = new Type[n][];

    La instrucción anterior crea una matriz de n filas. Cada elemento table[i] es una referencia a una matriz unidimensional. Estas referencias array[i] no se inicializan en la declaración anterior. Su valor es la referencia nula.

    El siguiente ejemplo ilustra la creación de una matriz de tablas:

    
            // un tableau de tableaux
            string[][] noms = new string[3][];
            for (int i = 0; i < noms.Length; i++) {
                noms[i] = new string[i + 1];
            }//for
            // initialisation
            for (int i = 0; i < noms.Length; i++) {
                for (int j = 0; j < noms[i].Length; j++) {
                    noms[i][j] = "nom" + i + j;
                }//for j
            }//for i
    • línea 2: una tabla «names» de 3 string[][]. Cada elemento es un puntero a una matriz (una referencia a un objeto) cuyos elementos son de tipo string[].
    • Líneas 3-5: se inicializan los 3 elementos de la tabla names. Cada uno «apunta» ahora a una matriz de elementos de tipo string[]. names[i][j] es la matriz de tipo string[] a la que hace referencia names[i].
    • línea 9: inicialización del elemento names[i][j] dentro de un bucle doble. Aquí, names[i] es una matriz de i+1 elementos. Como names[i] es una matriz, names[i].Length es su número de elementos.

    3.3.5.1. Interpretación de la operación de asignación

    La operación variable = expresión;

    es en sí misma una expresión cuya evaluación se lleva a cabo de la siguiente manera:

    • se evalúa el lado derecho de la asignación: el resultado es un valor V.
    • el valor V se asigna a la variable
    • el valor V es también el valor de la asignación, esta vez considerada como una expresión.

    Así es como el

        V1=V2=expression

    es válida. Debido a la prioridad, se evaluará el operador = situado más a la derecha. Por lo tanto, tenemos

        V1=(V2=expression)

    La expresión V2=expresión se evalúa y se le asigna el valor V. La evaluación de esta expresión ha provocado que se asigne V a V2. A continuación, el operador = siguiente se evalúa como:

        V1=V

    El valor de esta expresión sigue siendo V. Su evaluación hace que V se asigne a V1.

    Por lo tanto, la expresión V1=V2

    es una expresión cuya evaluación

    • hace que el valor de la expresión se asigne a las variables V1 y V2
    • da como resultado el valor de la expresión.

    Esto se puede generalizar a una expresión como:

    V1=V2=....=Vn=expression

    • La condición va entre corchetes.
    • Cada acción termina con un punto y coma.
    • Las llaves solo son necesarias si hay más de una acción.
    • La llave no va seguida de un punto y coma.

    La estructura algorítmica correspondiente es tantque :

    tantque condition
    actions
fintantque

    Estructura de repetición hasta (do while)

    La sintaxis es la siguiente:

    
    do{
       instructions;
    }while(condition);

    Repetimos el bucle hasta que la condición sea falsa. En este caso, el bucle se ejecuta al menos una vez.

    notas

    • La condición va entre corchetes.
    • Cada acción termina con un punto y coma.
    • Las llaves solo son necesarias si hay más de una acción.
    • la llave no va seguida de un punto y coma.

    La estructura algorítmica correspondiente es «repeat ... until»:

    répéter
    actions
jusqu'à condition

    La sintaxis es la siguiente:

    instructions; 
}

    notas

    • Las distintas instrucciones de instructions_depart y instructions_fin_boucle están separadas por comas.

    instructions_départ

    3.5. Gestión de excepciones

    Muchas funciones de C# pueden generar excepciones, es decir, errores. Cuando una función puede generar una excepción, el programador debe gestionarla con el objetivo de obtener programas más resistentes a los errores: siempre hay que evitar el «bloqueo» repentino de una aplicación.

    Una excepción se gestiona de la siguiente manera:

    try{
    code susceptible de générer une exception
} catch (Exception e){
    traiter l'exception e
}
instruction suivante

    Si la función no genera una excepción, pasamos a la instrucción siguiente; de lo contrario, pasamos al cuerpo de la cláusula catch y luego a la instrucción siguiente. Tenga en cuenta los siguientes puntos:

    • e es un objeto de tipo Exception o derivado. Se puede ser más preciso utilizando tipos como IndexOutOfRangeException, FormatException, SystemException, etc.: existen varios tipos de excepción. Al escribir catch (Exception e), se indica que se desea gestionar todos los tipos de excepción. Si es probable que el código del try genere varios tipos de excepción, es posible que se desee ser más preciso gestionando la excepción con varios catch: 
    try{
    code susceptible de générer les exceptions
} catch ( IndexOutOfRangeException e1){
    traiter l'exception e1
}
} catch ( FormatException e2){
    traiter l'exception e2
}
instruction suivante
    • Podemos añadir a las cláusulas try/catch una cláusula finally: 
    try{
    code susceptible de générer une exception
} catch (Exception e){
    traiter l'exception e
}
finally{
    code exécuté après try ou catch
}
instruction suivante

    Tanto si se produce una excepción como si no, la cláusula code finally siempre se ejecutará.

    • En el bloque catch, es posible que no quieras utilizar la excepción disponible. En lugar de escribir catch (Exception e){..}, escribimos catch(Exception){...} o simplemente catch {...}.
    • La clase Exception tiene una propiedad Message que es un mensaje que detalla el error que se ha producido. Así que, si queremos mostrarlo, escribiremos: 
    catch (Exception ex){
    Console.WriteLine("L'erreur suivante s'est produite : {0}",ex.Message);
    ...
}//catch
    • La clase Exception tiene un método ToString que devuelve una cadena que indica el tipo de excepción y el valor del Message. Por lo tanto, podemos escribir: 
    catch (Exception ex){
    Console.WriteLine("L'erreur suivante s'est produite : {0}", ex.ToString());
    ...
}//catch

    También podemos escribir:

    catch (Exception ex){
    Console.WriteLine("L'erreur suivante s'est produite : {0}",ex);
    ...
}//catch

    El compilador asignará al parámetro {0} el valor ex.ToString().

    class Impots {

             // data tables required for tax calculation
            decimal[] limites = { 4962M, 8382M, 14753M, 23888M, 38868M, 47932M, 0M };

             // marital status is restored

                Console.Write("Salaire annuel : ");

                    OK = salaire >= 0;
                } catch {
                 }// try
                if (!OK) {

                }
             }// while

    3.8. Enumeraciones

    Una enumeración es un tipo de datos cuyo dominio de valores es un conjunto de constantes enteras. Consideremos un programa que tiene que gestionar las calificaciones de un examen. Habría cinco de ellas: Aceptable, Bastante bien, Bien, Muy bien, Excelente.

    Podríamos entonces definir una enumeración para estas cinco constantes:

    
        enum Mentions { Passable, AssezBien, Bien, TrèsBien, Excellent };

    Internamente, estas cinco constantes se codifican mediante números enteros consecutivos, empezando por 0 para la primera constante, 1 para la siguiente, etc. Se puede declarar una variable para que adopte estos valores de la enumeración:

    
            // une variable qui prend ses valeurs dans l'énumération Mentions
Mentions maMention = Mentions.Passable;

    Una variable se puede comparar con los distintos valores posibles de la enumeración:

    
            if (maMention == Mentions.Passable) {
                Console.WriteLine("Peut mieux faire");
}

    Puedes obtener todos los valores de la enumeración:

    
             // list of statements in string form
            foreach (Mentions m in Enum.GetValues(maMention.GetType())) {
                Console.WriteLine(m);
}

    Del mismo modo que el tipo simple int es equivalente a System.Int32, el tipo simple enum es equivalente a System.Enum. Esta estructura tiene un método estático GetValues que permite obtener todos los valores de un tipo enumerado que se le pasa como parámetro. Este debe ser un objeto de tipo Type, que es una clase de información sobre el tipo de datos. El tipo de una variable v se obtiene mediante v.GetType(). El tipo de T se obtiene mediante typeof(T). Así, aquí maMention.GetType() devuelve el objeto Type de la enumeración Mentions y Enum.GetValues(maMention.GetType()) devuelve la lista de valores de la enumeración Mentions.

    Si ahora escribimos 

    
             //list of mentions in integer form
            foreach (int m in Enum.GetValues(typeof(Mentions))) {
                Console.WriteLine(m);
}

    En la línea 2, la variable del bucle es de tipo entero. A continuación, obtenemos la lista de valores de enumeración en forma de enteros. El objeto de tipo System.Type correspondiente al tipo de datos Mentions se obtiene mediante typeof(Mentions). Podríamos haber escrito maMention.GetType().

    3.9. Pasar parámetros a una función

    Aquí nos interesa la forma en que se pasan los parámetros a una función. Consideremos la siguiente función estática:

    
        private static void ChangeInt(int a) {
            a = 30;
            Console.WriteLine("Paramètre formel a=" + a);
}

    En la definición de la función, línea 1, a se denomina parámetro formal. Solo está ahí con el fin de definir la función changeInt. También podría haberse llamado b. Veamos ahora un ejemplo de uso de esta función:

    
        public static void Main() {
            int age = 20;
            ChangeInt(age);
            Console.WriteLine("Paramètre effectif age=" + age);
}

    Aquí, en la instrucción de la línea 3, ChangeInt(edad), edad es el parámetro efectivo que transmitirá su valor al parámetro formal a. Nos interesa saber cómo un parámetro formal recupera el valor de un parámetro efectivo.

    3.9.1. Pase por valor

    El siguiente ejemplo muestra que, por defecto, los parámetros de las funciones se pasan por valor, es decir, el valor del parámetro real se copia en el parámetro formal correspondiente. Tenemos dos entidades distintas. Si la función modifica el parámetro formal, el parámetro efectivo permanece inalterado.

    
using System;
 
namespace Chap1 {
    class P12 {
        public static void Main() {
            int age = 20;
            ChangeInt(age);
            Console.WriteLine("Paramètre effectif age=" + age);
        }
        private static void ChangeInt(int a) {
            a = 30;
            Console.WriteLine("Paramètre formel a=" + a);
        }
    }
}

    Los resultados son los siguientes:

    En una ejecución por referencia, el parámetro efectivo y el parámetro formal son una misma entidad. Si la función modifica el parámetro formal, el parámetro efectivo también se modifica. En C#, ambos deben ir precedidos de la palabra clave ref :
