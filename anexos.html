    14.1. El SGBD SQL Server Express 2005

    14.1.1. Instalación

    El SGBD SQL Server Express 2005 está disponible en la URL [http://msdn.microsoft.com/vstudio/express/sql/download/] :

    • en [1]: primero descargue e instale la plataforma .NET 2.0
    • en [2]: a continuación, instale y descargue SQL Server Express 2005
    • en [3]: a continuación, instala y descarga SQL Server Management Studio Express para administrar SQL Server

    La instalación de SQL Server Express crea una carpeta en [Inicio / Programas]:

    • en [1]: la aplicación de configuración de SQL Server. También permite iniciar/detener el servidor
    • en [2]: la aplicación de administración del servidor

    14.1.2. Iniciar/Detener SQL Server

    Al igual que con el SGBD anterior, SQL Server Express se ha instalado como un servicio de Windows de inicio automático. Ahora vamos a cambiar esta configuración:

    [Inicio / Panel de control / Rendimiento y mantenimiento / Herramientas administrativas / Servicios ] :

    • en [1]: hacemos doble clic en [Servicios]
    • en [2]: vemos que hay un servicio llamado [SQL Server], que está iniciado [3] y que se inicia automáticamente [4].
    • en [5]: otro servicio vinculado a SQL Server, llamado «SQL Server Browser», también está activo y se inicia automáticamente.

    Para cambiar esto, hacemos doble clic en el servicio [SQL Server]:

    • en [1]: configuramos el servicio para que se inicie manualmente
    • en [2]: lo detenemos
    • en [3]: se valida la nueva configuración del servicio

    Lo mismo se aplica al servicio [SQL Server Browser] (véase [5] más arriba). Para iniciar y detener el servicio SQL Server 2005, puede utilizar la aplicación [1] de la carpeta [SQL Server]:

    • en [1]: compruebe que el protocolo TCP/IP está activo (habilitado) y, a continuación, vaya a las propiedades del protocolo.
    • en [2]: en la pestaña [Direcciones IP], opción [IPAll]:
      • el campo [Puertos TCP dinámicos] se deja vacío
      • el puerto de escucha del servidor está configurado en 1433 en [Puerto TCP]
    • en [3]: haga clic con el botón derecho del ratón en el servicio [SQL Server] para acceder a las opciones de inicio/parada del servidor. Haga clic con el botón derecho del ratón en [Ici Server] para iniciarlo.
    • en [4]: se inicia SQL Server

    14.1.4. Creación de la tabla [ARTICLES] en la base de datos jpa

    Creamos una tabla [ARTICLES] a partir del siguiente script SQL:

    
/* table creation */
 
CREATE TABLE ARTICLES (
    ID            INTEGER NOT NULL,
    NOM           VARCHAR(20) NOT NULL,
    PRIX          DOUBLE PRECISION NOT NULL,
    STOCKACTUEL   INTEGER NOT NULL,
    STOCKMINIMUM  INTEGER NOT NULL
);
 
INSERT INTO ARTICLES (ID, NOM, PRIX, STOCKACTUEL, STOCKMINIMUM) VALUES (1, 'article1', 100, 10, 1);
INSERT INTO ARTICLES (ID, NOM, PRIX, STOCKACTUEL, STOCKMINIMUM) VALUES (2, 'article2', 200, 20, 2);
INSERT INTO ARTICLES (ID, NOM, PRIX, STOCKACTUEL, STOCKMINIMUM) VALUES (3, 'article3', 300, 30, 3);
 
/* integrity constraints */
 
ALTER TABLE ARTICLES ADD CONSTRAINT CHK_ID check (ID>0);
ALTER TABLE ARTICLES ADD CONSTRAINT CHK_PRIX check (PRIX>0);
ALTER TABLE ARTICLES ADD CONSTRAINT CHK_STOCKACTUEL check (STOCKACTUEL>0);
ALTER TABLE ARTICLES ADD CONSTRAINT CHK_STOCKMINIMUM check (STOCKMINIMUM>0);
ALTER TABLE ARTICLES ADD CONSTRAINT CHK_NOM check (NOM<>'');
ALTER TABLE ARTICLES ADD CONSTRAINT UNQ_NOM UNIQUE (NOM);
 
 
/* primary key */
 
ALTER TABLE ARTICLES ADD CONSTRAINT PK_ARTICLES PRIMARY KEY (ID);

    • en [3]: debes volver a identificarte (jpa/jpa)
    • en [4]: el script que se va a ejecutar
    • en [5]: selecciona la base de datos en la que se ejecutará el script
    • en [6]: ejecútelo
    • en [7]: el resultado de la ejecución: se ha creado la tabla [ARTICLES].
    • en [8]: solicitamos ver su contenido
    • en [9]: contenido de la tabla.

    14.1.5. El conector ADO.NET de SQL Server Express

    El conector ADO.NET es el conjunto de clases que permite a una aplicación .NET utilizar el SGBD SQL Server Express 2005. Las clases del conector se encuentran en el espacio de nombres [System.Data], disponible de forma nativa en todas las plataformas .NET.

    14.2. El SGBD MySQL5

    14.2.1. Instalación

    El SGBD MySQL5 está disponible en la URL [http://dev.mysql.com/downloads/] :

    • en [1]: seleccione la versión deseada
    • en [2]: elija una versión para Windows
    • en [3]: seleccione la versión de Windows deseada
    • en [4]: el archivo zip descargado contiene un ejecutable [Setup.exe] [4b] que debe extraerse y ejecutarse para instalar MySQL5
    • en [5]: seleccione una instalación típica
    • en [6]: una vez completada la instalación, puede configurar el servidor MySQL5
    • en [7]: elija una configuración estándar, la que plantee menos dudas
    • en [8]: el servidor MySQL5 será un servicio de Windows
    • en [9]: por defecto, el administrador del servidor es root sin contraseña. Puede mantener esta configuración o asignar una nueva contraseña a root. Si la instalación de MySQL5 se realiza tras la desinstalación de una versión anterior, esta operación puede fallar. Hay menos formas de recuperarla.
    • en [10]: se solicita la configuración del servidor

    La instalación de MySQL5 crea una carpeta en [Inicio / Programas]:

    Puede utilizar el [Asistente de configuración de instancias del servidor MySQL] para reconfigurar el servidor:

    • en [3]: cambiamos la contraseña de root (aquí root/root)

    14.2.2. Iniciar/Detener MySQL5

    El servidor MySQL5 se ha instalado como un servicio de Windows de inicio automático, de modo que se inicia tan pronto como se inicia Windows. Este modo de funcionamiento no es muy práctico. Vamos a cambiarlo:

    [Inicio / Panel de control / Rendimiento y mantenimiento / Herramientas administrativas / Servicios ] :

    • en [1]: hacemos doble clic en [Servicios]
    • en [2]: vemos que hay un servicio llamado [MySQL], que está iniciado [3] y que se inicia automáticamente [4].

    Para cambiar esto, hacemos doble clic en el servicio [MySQL]:

    • en [1]: configuramos el servicio para que se inicie manualmente
    • en [2]: lo detenemos
    • en [3]: se valida la nueva configuración del servicio

    Para iniciar y detener manualmente el servicio MySQL, puede crear dos accesos directos:

    • en [1]: el acceso directo para iniciar MySQL5
    • en [2]: el acceso directo para detenerlo

    14.2.3. Administración de clientes MySQL

    En la página web de MySQL, puede encontrar clientes de administración para el SGBD:

    • en [1]: seleccione [MySQL GUI Tools], que reúne varios clientes gráficos para administrar y manejar el SGBD
    • en [2]: seleccione la versión adecuada para Windows
    • en [3]: se descarga un archivo .msi para su ejecución
    • en [4]: una vez completada la instalación, aparecerán nuevos accesos directos en la carpeta [Menú Inicio / Programas / mySQL].

    Ejecutemos MySQL (a través de los accesos directos que has creado) y, a continuación, ejecutemos [MySQL Administrator] a través del menú anterior:

    • en [1]: introduce la contraseña de usuario root (root aquí)
    • en [2]: ya has iniciado sesión y MySQL está activo

    14.2.4. Creación de un usuario JPA y una base de datos JPA

    Ahora crearemos una base de datos llamada jpa y un usuario con el mismo nombre. Primero, el usuario:

    • en [1]: selecciona [Administración de usuarios]
    • en [2]: haz clic con el botón derecho en la sección [Cuentas de usuario] para crear un nuevo usuario
    • en [3]: el nombre del usuario es jpa y su contraseña es jpa
    • en [4]: valida la creación
    • en [5]: el usuario [jpa] aparece en la ventana [Cuentas de usuario]

    La base de datos ahora:

    • en [1]: seleccione la opción [Catálogos]
    • en [2]: haz clic con el botón derecho del ratón en la ventana [Esquemas] para crear un nuevo esquema (designando una base de datos)
    • en [3]: nombramos el nuevo diagrama
    • en [4]: aparece en la ventana [Esquemas]
    • en [5]: selecciona el esquema [jpa]
    • en [6]: aparecen los objetos del esquema [jpa], incluidas las tablas. Todavía no hay ninguno. Haz clic con el botón derecho para crear uno. Dejamos eso al lector.

    Volvamos al usuario [jpa] y otorguémosle todos los derechos sobre el esquema [jpa]:

    • en [1], luego en [2]: se selecciona el usuario [jpa]
    • en [3]: selecciona la pestaña [Privilegios de esquema]
    • en [4]: selecciona el esquema [jpa]
    • en [5]: le daremos al usuario [jpa] privilegios completos sobre el esquema [jpa]
    • en [6]: valida los cambios realizados

    Para comprobar que el usuario [jpa] puede trabajar con el esquema [jpa], cerramos el administrador de MySQL. Lo reiniciamos y, esta vez, nos conectamos con el nombre [jpa/jpa]:

    • en [1]: nos identificamos (jpa/jpa)
    • en [2]: la conexión se ha establecido correctamente y en [Schemata] vemos los esquemas sobre los que tenemos derechos. Vemos el esquema [jpa].

    Ahora vamos a crear una tabla [ARTICLES] utilizando un script SQL.
